# Optional original C math

The source backup does not include `libalgorithms` or OBJECTIVE 28 recovery.
The complete Python thesis strategies and the independent native SHA-256 engine are included.

If you later recover the original compatible libraries, put their full directory tree here:

```
optional/c. math/algorithms/libalgorithms.dylib
optional/c. math/math/lib/...
optional/c. math/lib/recovery_core/librecovery_core.dylib
optional/c. math/python/recovery/...
```

Enable `native_nonce`, `native_candidates` or `recovery` only after supplying an Apple Silicon-compatible original build.
The existing optional library interfaces are retained from the source miner. They have not been validated in this package.
